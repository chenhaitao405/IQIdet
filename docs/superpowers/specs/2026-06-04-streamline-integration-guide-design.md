# 精简集成引导.md 设计

## 目标

将 `集成引导.md` 从 760 行压缩到 ~80 行极简上手页，面向前端/后端集成同事首次接入。

## 砍掉内容

- 所有 FastAPI 完整路由示例代码
- 所有完整 JSON 请求/响应示例
- CLI 参数全量展开（只保留最小命令）
- "直接调用底层服务类"的 cv2 示例
- 公式推导和错误响应示例
- 冗长的"如果你们按旧版…"迁移说明

## 保留但压缩

- 三个功能的入口文件路径 + 核心 import/调用签名（一行代码风格）
- 模型文件清单（表格，不展开解释）+ Git LFS 最简命令
- 功能边界说明（"负责/不负责" 各 1-2 行）
- 输出核心字段（只列关键字段名，不解释含义）

## 最终结构

```
# IQIdet 集成速查

## 1. 前置条件
  - conda 环境激活 + requirements
  - 模型文件清单（5 行表格）
  - Git LFS 拉取命令（1 行）

## 2. 功能速查
  ### 2.1 底片信息自动识别
    - 入口: run_iqi_grade_infer.py
    - 最小命令（3 行）
    - 输出核心字段（7 个字段名）
    - 负责/不负责（各 1 行）
    - 详文链接

  ### 2.2 区域 OCR 识别
    - 入口: region_ocr_api.py
    - 核心调用（3 个函数签名）
    - 输入/输出（字段名列）
    - 负责/不负责（各 1 行）

  ### 2.3 区域归一化信噪比
    - 入口: region_SNR_api.py
    - 核心调用（3 个函数签名）
    - 输入/输出（字段名列）
    - 负责/不负责（各 1 行）
    - 面积约束提示

## 3. 建议组合方式
  - 表格：3 种需求 → 对应功能 + 离线/在线

## 4. 常见注意事项
  - 5 条，一条一行

## 5. 详细文档
  - 3 个链接
```

## 实施

直接覆写 `集成引导.md`，不新增文件。原有详细内容皆可通过文末链接获取。commit 信息：

```
docs: 精简集成引导.md，从 760 行压至 ~80 行极简上手页
```

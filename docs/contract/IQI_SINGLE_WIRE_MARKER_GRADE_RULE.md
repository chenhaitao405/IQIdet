# 单丝型像质计标记与等级判定契约

本文用于约束 IQIdet 中单丝型像质计的标记解析与等级计算规则，服务于 `gauge/iqi_rules.py` 中 `compute_iqi_grade` 及其上游标记解析逻辑的维护。

## 1. 标准来源与适用边界

来源文件：

- `docs/contract/JBT 7902-2025《无损检测 丝型像质计通用规范》.pdf`

注意事项：

- 本地文件名使用 `2025`，但 PDF 正文页眉显示为 `JB/T 7902—2024`，首页显示为报批稿。开发时应以本仓库归档的 PDF 内容为当前规则依据。
- 该文件规定的是丝型像质计的材料、型式、标记、技术要求和制造检验等内容，不是完整的射线底片验收规范。
- 本文只总结单丝型像质计，包括通用单丝型像质计和专用单丝型像质计；不覆盖双丝型像质计。

## 2. 标准中的单丝型像质计分类

标准第 3 章和第 4.2 节将单丝型像质计分为两类：

| 标准类型 | 标准含义 | 结构特征 | 项目建议内部类型 |
| --- | --- | --- | --- |
| 通用单丝型像质计 | 由不同直径的系列金属丝组成，用于测量射线检测图像像质值 | 每组 7 根连续丝号的不同直径金属丝 | `general` |
| 专用单丝型像质计 | 由相同直径的系列金属丝组成，用于测量射线检测图像像质值 | 3 根到 5 根相同丝号、相同直径的金属丝 | `special` |

工程实现中不应再用材料代号判断像质计类型。`FE`、`NI`、`SS`、`CU`、`TI`、`AL`、`ZR` 等是材料代号，不是通用/专用类型。

如果沿用旧代码中的命名，建议建立明确映射：

- `general`：旧代码中按不同丝径递增计算等级的类型。
- `special`：旧代码中等级等于标记丝号的类型。

## 3. 材料代号

标准第 4.1.1.2 节列出单丝型像质计常用材料代号：

| 材料代号 | 含义 |
| --- | --- |
| `FE` | 铁基，合金含量低的钢 |
| `SS` | 不锈钢材料，适用于不锈钢质材料检测时可使用 |
| `CU` | 铜及铜合金 |
| `TI` | 钛及钛合金 |
| `AL` | 铝及铝合金 |
| `NI` | 镍及镍合金 |
| `ZR` | 锆及锆合金 |

材料代号用于判断像质计材料是否与被检材料匹配，不参与通用/专用类型判断，也不直接决定等级计算公式。

## 4. 通用单丝型像质计标记

标准第 4.2.1.1 节规定通用单丝型像质计分为 `W1`、`W6`、`W10`、`W13` 四组，每组包含 7 根连续丝号的金属丝：

| 组别 | 内含丝号 | 标记中的数字 |
| --- | --- | --- |
| `W1` | `1-7` | `1` |
| `W6` | `6-12` | `6` |
| `W10` | `10-16` | `10` |
| `W13` | `13-19` | `13` |

标准第 4.3.1 节给出的通用单丝型像质计标记样式为：

```text
10 FE JB
```

其含义是：

- `10`：本组中最大直径金属丝的丝号，也就是该组起始丝号。
- `FE`：金属丝材料代号。
- `JB`：符合本文件。

因此，通用单丝型像质计的工程解析规则为：

```text
<起始丝号> <材料代号> <标准标识>
```

OCR 归一化后可接受无空格形式，例如 `10FEJB`。

## 5. 专用单丝型像质计标记

标准第 4.2.1.2 节规定专用单丝型像质计由 3 根到 5 根相同直径、同一丝号的金属丝构成。这里的 3 根到 5 根是像质计实体结构描述，不是本项目底片等级输出的最小可见根数门槛。

标准第 4.3.2 节给出的专用单丝型像质计标记样式为：

```text
FE 10 JB
```

其含义是：

- `FE`：金属丝材料代号。
- `10`：本组对应的金属丝丝号。
- `JB`：符合本文件。

因此，专用单丝型像质计的工程解析规则为：

```text
<材料代号> <丝号> <标准标识>
```

OCR 归一化后可接受无空格形式，例如 `FE10JB`。

## 6. 标记顺序决定类型

通用和专用的关键区别是标记顺序：

| OCR 归一化标记 | 标准类型 | 等级公式 |
| --- | --- | --- |
| `10FEJB` | 通用单丝型像质计 | `grade = 起始丝号 + 可见丝数 - 1` |
| `FE10JB` | 专用单丝型像质计 | `grade = 标记丝号` |

实现要求：

- `数字 + 材料代号 + JB` 判为通用单丝型像质计。
- `材料代号 + 数字 + JB` 判为专用单丝型像质计。
- 材料代号不能用于判断通用或专用。
- 标记顺序不清或同时可解释为多个冲突候选时，应返回标记歧义错误，而不是猜测类型。

标准第 4.3.1 注释中说明，符合本文件且带有 `GB`、`ISO` 等字母的像质计可等同使用。当前工程可先以 `JB` 为主要标准标识；如后续需要兼容 `GB`、`ISO`，应只扩展标准标识解析，不改变本文的类型和等级公式。

## 7. 等级判定规则

### 7.1 通用单丝型像质计

通用单丝型像质计由不同直径的连续丝号组成，标记数字代表该组最大直径金属丝的丝号，即起始丝号。

工程等级公式：

```text
grade = 起始丝号 + 可见丝数 - 1
```

有效条件：

- 标记必须成功解析为通用单丝型像质计。
- 起始丝号应为 `1`、`6`、`10`、`13` 之一。
- `wire_count` 应至少为 `1`。
- 标准结构上每组只有 7 根丝，因此用于等级计算的 `wire_count` 不应超过 `7`；超过时应按模型或解析异常处理，不输出有效等级。

示例：

| 标记 | 可见丝数 `wire_count` | 输出等级 |
| --- | ---: | ---: |
| `10 FE JB` | `1` | `10` |
| `10 FE JB` | `3` | `12` |
| `6 FE JB` | `7` | `12` |

### 7.2 专用单丝型像质计

专用单丝型像质计由相同直径、同一丝号的多根金属丝构成，标记数字代表该专用像质计对应的丝号。

工程等级公式：

```text
grade = 标记丝号
```

有效条件：

- 标记必须成功解析为专用单丝型像质计。
- 标记丝号应落在标准表 1 的单丝丝号范围内，即 `1-19`。
- `wire_count` 应至少为 `1`，表示底片中至少确认有一根该专用像质计金属丝可见。

特别说明：

- 标准中的 3 根到 5 根是专用单丝型像质计的实体结构描述。
- 本项目与客户沟通后的工程判定约定是：只要能识别到其中一根有效金属丝，就可以按标记丝号输出像质计等级。
- 因此，专用单丝型像质计不使用 `3 <= wire_count <= 5` 作为等级输出门槛。
- 如果 `wire_count` 大于 5，可作为模型计数异常或诊断信息记录，但不改变 `grade = 标记丝号` 的等级公式。

示例：

| 标记 | 可见丝数 `wire_count` | 输出等级 |
| --- | ---: | ---: |
| `FE 10 JB` | `1` | `10` |
| `FE 10 JB` | `3` | `10` |
| `NI 13 JB` | `1` | `13` |

## 8. 对 `compute_iqi_grade` 的接口建议

为了避免继续混淆材料和类型，建议等级计算使用标准语义输入：

```text
iqi_kind: "general" | "special"
marker_number: int
wire_count: int | None
```

其中：

- `iqi_kind` 来自标记顺序解析，不来自材料代号。
- `marker_number` 对通用单丝型表示起始丝号，对专用单丝型表示对应丝号。
- `wire_count` 来自像质丝识别模型。

建议输出规则：

| 场景 | 结果 |
| --- | --- |
| 标记类型未知 | 标记解析失败，不调用或不成功返回等级计算 |
| 通用单丝型，`wire_count` 缺失或小于 1 | 等级失败 |
| 通用单丝型，`wire_count` 大于 7 | 等级失败，记录计数异常 |
| 专用单丝型，`wire_count` 缺失或小于 1 | 等级失败 |
| 专用单丝型，`wire_count` 至少为 1 | `grade = marker_number` |

## 9. 与现有代码的差异点

当前 `gauge/iqi_rules.py` 周边文档和逻辑中存在历史规则：

- `FE -> uniform`
- `NI -> gradient`
- `E+J -> uniform`
- `I+J -> gradient`

该规则会把材料代号误当成像质计类型。按本契约，后续应改为：

- 先从标记顺序判断 `general` 或 `special`。
- 再解析材料代号，仅作为材料字段保存。
- 最后按 `general` 或 `special` 调用对应等级公式。

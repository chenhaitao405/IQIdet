## 调研范围

调研 ISO 19232-5 / ASTM E2002 / JBT 7902 双丝型像质计的分辨率自动判定方法，聚焦三个核心问题：

1. **峰谷检测**：如何从灰度剖面曲线自动检测波峰、波谷
2. **区域 A/B/C 判定**：a、b、c 三个灰度值的来源区域如何定义
3. **Contrast 计算**：调制度公式的实现细节与首个不可分辨组的判定策略

调研来源：ISO 标准（19232-5:2018）、中国专利（CN120253177A、CN202310432344.9）、无损检测期刊论文（Sun 2017, 2024 灰度直方图法）、电子科大硕士论文（甘长鑫 2023）、2025 OPE 期刊 CTF 论文（杨庆国等）、ASTM E2002。

## 1. 公式与符号定义

### 1.1 核心公式

双丝调制度（Dip / Modulation Depth）的判定公式：

$$R = \frac{a + b - 2c}{a + b} \times 100\%$$

其中 **a、b、c** 对应剖面灰度曲线上每对双丝的 **三个关键位置**：

| 符号 | 正片含义 | 负片含义 | 剖面形态 |
|------|---------|---------|----------|
| **a** | 第一根丝的灰度值（丝→暗→局部极小值） | 第一根丝的灰度值（丝→亮→局部极大值） | 波谷1 |
| **c** | 两丝间隙的灰度值（间隙→亮→局部极大值） | 两丝间隙的灰度值（间隙→暗→局部极小值） | 波峰（正片） |
| **b** | 第二根丝的灰度值（局部极小值） | 第二根丝的灰度值（局部极大值） | 波谷2 |

正片剖面形态：**谷(a)-峰(c)-谷(b)**  
负片剖面形态：**峰(a)-谷(c)-峰(b)**

### 1.2 判定阈值

- **标准阈值**：$R < 20\%$（即 $R < 0.20$）时，该线对不可分辨
- 从最粗组（D1）向最细组遍历，**第一个 $R < 20\%$ 的组**即为系统可识别的最小分辨率组
- 该组对应的丝径 d 即为基本空间分辨率 SRb，$U_T = 2d$ 为总不清晰度

## 2. 方案一：峰谷检测

### 2.1 方案 A：基于 scipy.signal.find_peaks()（推荐）

spec 已预留此方案，利用 `scipy.signal.find_peaks()` 检测局部极值。

```python
from scipy.signal import find_peaks

# 正片：丝是暗区 → valley 在 profile 中为局部极小值
valleys, _ = find_peaks(-profile, distance=min_distance, prominence=prominence)

# 正片：间隙是亮区 → peak 在 profile 中为局部极大值
peaks, _ = find_peaks(profile, distance=min_distance, prominence=prominence)
```

**参数调优：**

| 参数 | 含义 | 建议取值 | 依据 |
|------|------|---------|------|
| `distance` | 相邻峰/谷的最小间距（像素） | 2~20（取决于放大比和像素间距） | 2024 灰度直方图论文："双丝间距阈值 $D_{max}=20, D_{min}=2$" |
| `prominence` | 峰/谷显著性阈值 | `0.05 * (max(profile) - min(profile))` | 自适应阈值优于固定值，避免在不同图像亮度下失效 |

**适用条件**：`band_width=21` 的束带平均已提供充分平滑，直接对原始剖面用 `find_peaks()` 大概率足够。

### 2.2 方案 B：插值平滑 + 极值搜索（高精度备选）

专利 CN120253177A 提出先用改进 Akima 插值平滑剖面，再搜索局部极值：

```python
from scipy.interpolate import Akima1DInterpolator

x_original = np.arange(len(profile))
x_interp = np.linspace(0, len(profile)-1, len(profile) * 4)   # 4× 超采样
profile_smooth = Akima1DInterpolator(x_original, profile)(x_interp)
```

**Akima 优势**：相比三次样条减少了过冲（overshoot），2025 年杨庆国等 CTF 论文特别指出这对 MTF 测量精度至关重要。

**适用条件**：当方案 A 的峰谷检测不稳定（噪声大、假谷多）时引入。对 Phase 2 而言非必需。

### 2.3 峰谷配对策略

检测出所有 peaks 和 valleys 后，配对成"双丝组"：

```python
def pair_peaks_valleys(profile, peaks, valleys):
    """
    配对: valley[i], peak_between, valley[i+1] → 一组双丝
    
    对于正片: valleys 是丝的暗区, peaks 是间隙亮区
    每对双丝 = 两个相邻 valley + 它们之间的 peak
    """
    pairs = []
    for i in range(len(valleys) - 1):
        v1, v2 = valleys[i], valleys[i+1]
        # 找 v1 和 v2 之间的 peak
        between = peaks[(peaks > v1) & (peaks < v2)]
        if len(between) == 1:
            pairs.append((v1, between[0], v2))
        elif len(between) > 1:
            # 多 peak：取最高的（正片）
            best = between[np.argmax(profile[between])]
            pairs.append((v1, best, v2))
        # len == 0: 噪声假谷，跳过
    return pairs
```

**异常处理：**

| 异常 | 原因 | 处理 |
|------|------|------|
| 峰谷数量不匹配 | 噪声假谷 | `prominence` 阈值过滤 |
| 谷间距过大 | 图像边缘或非丝区域 | `distance` 上限过滤 |
| 谷间距过小 | 噪声假谷 | `distance` 下限过滤 |
| valley 之间无 peak | 双丝已完全融合（不可分辨） | 该组 R ≈ 0，可直接判定 |

## 3. 方案二：区域 A/B/C 的判定方法

这是 Phase 2 最核心的设计决策——a、b、c 是取单像素值还是区域均值，区域边界如何划分。

### 3.1 方案 A：单点极值法（baseline）

对每对双丝，取 3 个极值点对应的单一像素值：

```python
a = profile[valley_1_idx]   # 左侧丝 → 局部极小值
c = profile[peak_idx]       # 中间间隙 → 局部极大值
b = profile[valley_2_idx]   # 右侧丝 → 局部极小值
```

| 优点 | 风险 |
|------|------|
| 最简单，spec 已预留 `detect_peaks_valleys()` | 单像素对噪声敏感 |
| 束带平均（`band_width=21`）已沿列方向去噪 | 剖面线方向噪声无额外抑制 |

**适用**：信噪比较好的图像，作为 baseline 快速验证。

### 3.2 方案 B：邻域均值法（推荐）

以每个极值点为中心取邻域窗口（半宽 w），用窗口内 **均值** 作为 a/b/c：

```python
def compute_wire_pair_contrast(profile, v1_idx, p_idx, v2_idx, half_w=3):
    """用邻域均值计算单组双丝对比度"""
    a = profile[max(0, v1_idx - half_w) : min(len(profile), v1_idx + half_w + 1)].mean()
    c = profile[max(0, p_idx  - half_w) : min(len(profile), p_idx  + half_w + 1)].mean()
    b = profile[max(0, v2_idx - half_w) : min(len(profile), v2_idx + half_w + 1)].mean()
    return (a + b - 2 * c) / (a + b)

# 指定区域索引方便标注可视化
# Region A 索引: [v1_idx - half_w, v1_idx + half_w]
# Region C 索引: [p_idx  - half_w, p_idx  + half_w]
# Region B 索引: [v2_idx - half_w, v2_idx + half_w]
```

**文献依据**：2024 灰度直方图 20% 下凹法论文明确指出：
> "a、b：双丝中丝对对应各像素的**最小灰度的平均值**"  
> "c：双丝对中像素**最高灰度值的平均值**"

即：在剖面线方向上，不是取单个极值像素，而是取极值附近一段区域的灰度均值。

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `half_w` | 3（窗口宽 7 像素） | 默认值，可通过 CLI `--window-half-width` 调节 |
| `half_w=0` | 退化 | 退化为方案 A 单点极值 |
| `half_w=5` | 粗丝场景 | 粗丝的丝径大，可使用更大窗口 |

**ISO 19232-5 的测量要求**提到："不少于 21 行或列像素叠加平均"（指束带方向，平行于丝）。方案 B 在剖面线方向（垂直于丝）进一步用邻域平均，是互补的降噪策略。

### 3.3 方案 C：全段积分法（高精度备选）

不取固定窗口，而是用相邻极值点之间的 **自然分段** 作为区域边界：

```
剖面: valley[i-1] -- peak[i-1] -- valley[i] -- peak[i] -- valley[i+1]
                     ↑                                   ↑
                 left_mid                            right_mid

Region A (左丝) = profile[left_mid : peak[i-1]]
Region C (间隙) = profile[peak[i-1] : right_mid]  → c = mean(Region C)
Region B (右丝) = 由下一个边界的左侧段定义        → b = mean(Region B)
```

| 优点 | 缺点 |
|------|------|
| 自适应丝距，无固定参数 | 边界检测对噪声敏感 |
| 对粗丝和细丝一视同仁 | 边界处含信号过渡区 |

**适用**：高精度场景，配合插值平滑后的剖面使用。Phase 2 暂不推荐优先实现。

### 3.4 方案对比总结

| 维度 | 方案 A 单点 | 方案 B 邻域均值 | 方案 C 全段积分 |
|------|-----------|---------------|---------------|
| 复杂度 | ⭐ | ⭐⭐ | ⭐⭐⭐⭐ |
| 噪声鲁棒性 | 低 | 中 | 高 |
| 文献支持 | — | 中国无损检测期刊 2024 | 理论推导 |
| 参数数量 | 0 | 1 (`half_w`) | 0（但需边界检测逻辑） |
| 退化风险 | — | half_w=0 → 方案 A | 边界检测失败 |
| **推荐度** | baseline | **Phase 2 首选** | 后续迭代 |

## 4. 开源参考实现：BAM ctsimu-toolbox

德国联邦材料研究与测试研究所（BAM）开源的 `ctsimu-toolbox` 是当前最成熟的双丝 IQI 自动分析实现，完整遵循 ASTM E2002 规范。其实现细节对 Phase 2 有重要参考价值。

### 4.1 核心流程

```
1. 沿 RDI 方向提取灰度剖面线（对应 spec 中剖面带平均）
2. 二次背景拟合（scipy.optimize.curve_fit → quadratic）
3. 在去背景后的剖面中检测 valleys（scipy.signal.find_peaks）
4. 谷配对 + 峰定位 → 逐组计算 dip
5. 二次插值求解 iSRb（dip=20% 对应的丝径）
```

### 4.2 关键实现细节

#### a) 二次背景拟合

不同于直接使用原始剖面灰度值，ctsimu-toolbox 先用 `scipy.optimize.curve_fit` 对剖面数据做二次曲线拟合作为背景估计，再计算去背景后的调制深度：

```python
# BAM 做法（伪代码）
bg_params, _ = curve_fit(lambda x, a, b, c: a*x**2 + b*x + c, x, profile)
background = bg_params[0]*x**2 + bg_params[1]*x + bg_params[2]
profile_debg = profile - background  # 去背景后的剖面
```

**目的**：消除 X 射线束的不均匀照射（heel effect）导致的剖面基线偏移，使 dip 计算不依赖于绝对灰度。

**Phase 2 考虑**：如果双丝 ROI 较小（在图像中局部区域），背景变化有限，此步可跳过。若全图提取长剖面（跨越整个 IQI），则背景拟合很有价值。

#### b) Dip 公式（与 ISO 一致）

```python
dip = 100 * (A + B - 2*C) / (A + B)
# 其中 A, B = 谷底到背景的深度（backgound - valley_value）
#      C = 峰顶到背景的深度（backgound - peak_value）
```

与 ISO 标准公式 $$R = \frac{a + b - 2c}{a + b}$$ **完全一致**，区别仅在于 ctsimu 先减背景，使其在灰度反向（正/负片）上自然统一。

#### c) 谷配对策略

```python
# 核心逻辑：相邻谷间距不超过第一对间距的 1.05 倍
dist_max = 1.05 * dist[0]  # 以最粗丝对间距为基准
# 从第二个谷开始，只有间距 > dist_max 时才认为是新对的开始
```

**Phase 2 启示**：峰谷配对可以用最粗丝对间距作为锚点，自动过滤噪声假谷，优于固定像素阈值。

#### d) 插值求 iSRb

```python
# 二次拟合 dip = f(wire_spacing)，解 f(d) = 20%
coeffs = np.polyfit(spacings, dips, 2)
a, b, c = coeffs
roots = np.roots([a, b, c - 20.0])

# 根据曲率选择有效根
if a >= 0:
    isrb = max(roots)   # 开口向上 → 取大根
else:
    isrb = min(roots)   # 开口向下 → 取小根
```

#### e) 排除低调制组

```python
# dip < 1.5% 的组从插值邻域中排除
# 源码注释: "to prevent unpleasant fits"
# 背景拟合误差在低调制区被放大，会破坏插值稳定性
```

### 4.3 与本文方案的对应关系

| BAM ctsimu-toolbox | 本文推荐方案 |
|---|---|
| `curve_fit` 二次背景 | 可选（ROI 小则跳过） |
| `find_peaks` 谷检测 | §2.1 方案 A，参数建议一致 |
| 邻域均值 A/B/C | §3.2 方案 B |
| `dip = (A+B-2C)/(A+B)` | §1.1 核心公式 |
| `dist_max = 1.05 * dist[0]` | §2.3 配对策略改进参考 |
| 二次插值 iSRb | §4.2 插值法 |
| 排除 dip < 1.5% | 新增（§3.2 未覆盖） |

### 4.4 Sun Chaoming (2017) 的公式变体

Sun (2017) 使用了 **不同公式**：

$$R = \frac{A - B}{A} = 1 - x, \quad x \in [0, 1]$$

其中 A = 峰-背景，B = 谷-背景，x = 归一化后的谷灰度值。该方法将剖面按固定长度（71 像素）分段并归一化到 [0, 1]。

**注意**：这与 ISO 19232-5 的 $$R = \frac{a+b-2c}{a+b}$$ 在数学上不等价。ISO 公式更通用（适用于非对称峰高），Phase 2 应遵循 ISO 公式。

Sun 论文还报告了三种**被淘汰**的方法：
- 差分峰值搜索 + 阈值（参数太多、适应性差）
- 高斯曲线拟合 2~3 分量（拟合质量差）
- 神经网络识别（泛化差、定量精度低）

这些可作为 Phase 2 不推荐的路径参考。

## 5. 方案三：Contrast 计算与首个不可分辨组判定

### 5.1 基本遍历判定（Phase 2 必做）

```python
def find_first_unresolved_group(
    wire_pairs: list[tuple[int, int, int]],  # [(v1, p, v2), ...], 从粗到细
    profile: np.ndarray,
    threshold: float = 0.20,
    half_w: int = 3,
) -> int | None:
    """
    从粗到细遍历，返回第一个 Contrast < threshold 的组编号（1-indexed）。
    None 表示全部可分辨。
    """
    for i, (v1, p, v2) in enumerate(wire_pairs):
        R = compute_wire_pair_contrast(profile, v1, p, v2, half_w)
        if R < threshold:
            return i + 1   # 1-indexed
    return None
```

### 5.2 插值法提高精度（Phase 2.5 可选）

标准离散判定精确到 ±1 组。论文（2024 灰度直方图法、CN120253177A）提出用**二次拟合**达到 ±0.5 组精度：

```python
def interpolate_resolution(
    wire_diameters: list[float],  # 各组丝径
    R_values: list[float],        # 各组 R 值
    threshold: float = 0.20,
) -> float | None:
    """
    二次拟合 R = f(d)，解 f(d) = threshold 得到精确分辨率丝径。
    返回丝径 d 对应基本空间分辨率 SRb。
    """
    coeffs = np.polyfit(wire_diameters, R_values, deg=2)
    a, b, c = coeffs
    roots = np.roots([a, b, c - threshold])
    valid = roots[(roots > min(wire_diameters)) & (roots < max(wire_diameters))]
    return float(valid[0]) if len(valid) > 0 else None
```

**依据**：CN120253177A "采用二次曲线拟合，计算调制度为 20% 对应的丝径值"。

### 5.3 正/负片自动判定

$$R = \frac{a + b - 2c}{a + b}$$

此公式在正负片上 **自然统一**：

| 片型 | a, b 对应 | c 对应 | 公式行为 |
|------|----------|--------|---------|
| 正片 | 两个波谷（低灰度） | 波峰（高灰度） | c > a,b → R 大 |
| 负片 | 两个波峰（高灰度） | 波谷（低灰度） | c < a,b → R 大 |

**核心差异仅在于峰谷检测时的方向**：负片时 valleys 变 peaks，peaks 变 valleys。自动判定用 D1 的信号方向：

```python
def detect_film_type(profile, valleys, peaks):
    """基于 D1 判正/负片"""
    if len(valleys) >= 2 and len(peaks) >= 1:
        # 正片：间隙灰度 > 丝灰度（valley 是丝，peak 是间隙）
        a_val = profile[valleys[0]]
        c_val = profile[peaks[0]]
        return "positive" if c_val > a_val else "negative"
    return "positive"  # 默认
```

### 5.4 边角情况

| 情况 | 处理 |
|------|------|
| 所有组 $R \ge 20\%$ | 返回 `None`（全部可分辨，超出量程上限） |
| 最粗组即 $R < 20\%$ | 返回 D1（图像质量极差） |
| 部分组峰谷配对失败 | 跳过该组，不影响其他组判定 |
| 分段双丝像质计 | 需额外输入每段第一组的编号映射 |

### 理由

1. 方案 B 有明确文献支持（中国无损检测期刊 2024、Sun 2017）
2. 实现复杂度低，与现有 spec（`detect_peaks_valleys` 预留）自然衔接
3. `half_w` 可配置，退化到 `half_w=0` 即为方案 A（单点极值）
4. `band_width=21` 的束带平均已在列方向去噪，剖面线方向再加邻域平均是互补策略
